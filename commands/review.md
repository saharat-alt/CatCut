Use the CatCut MCP tools.

Open the local review page for version $ARGUMENTS (default: latest) with `review_open` and give the user the URL.
Explain in one line: pick a pen colour (red = cut, yellow = timing, blue = text/graphic, green = colour, purple = audio), circle the spot, optional note, press send. B toggles A/B, W wipes between versions.
When the user says they sent it, continue with `/catcut:fix`.
